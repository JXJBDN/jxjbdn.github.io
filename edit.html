落笔即成稿 · 发布后约 1 分钟线上生效

钥

首次使用：连接你的 GitHub

发布功能需要一枚「细粒度令牌」——相当于一把只能开你这一个仓库、只能写文章文件的钥匙。也可以直接打开 令牌生成页，按下面 6 步填：

  1. 打开 github.com，点右上角头像 → Settings
  2. 拉到左侧最底部 → Developer settings → Personal access tokens → Fine-grained tokens
  3. 点 Generate new token：名字随便填（如 my-website），Expiration 选 No expiration
  4. Repository access 选 Only select repositories → 只勾选 jxjbdn/jxjbdn.github.io
  5. Permissions → Repository permissions → 找到 Contents → 选 Read and write（其他一律不动）
  6. 点 Generate，复制以 github_pat_ 开头的一长串，粘贴到下面
稿
插到光标处，发布后自动同步进「相册」（视频 ≤ 15MB，建议 mp4）
空一行 = 分一段 0 字
正在同步网站标签……
草稿会自动保存在本机
编辑已发布的日记（改错字 · 随时改）

点「编辑」把日记装回上面的稿纸，改完点「保存修改」。保存后日记时间会更新为编辑时间，文末自动留下「编修留痕」，初稿和每次修改的时间都不会丢。图片视频会原样带回，不用重新上传。

载入中……
整理标签（删除 · 排序）

改动会立即写回网站的首页和日记页标签栏，约 1 分钟后线上生效。删除标签不影响文章本身；一个标签不剩的日记会自动落入「待定」，不怕误删。

载入中……
管理日记标签（随时改）

点某篇日记的「改标签」，重新勾选后保存。改动会同步首页卡片、日记页卡片和文章页。

载入中……
友链管理（好友网站）

添加好友的网站，会展示在导航栏的「友链」页面。网址不带 http:// 也行，会自动补全。

载入中……
公告管理（发布 · 撤下）

发布公告后，访客每次打开网站，公告会从顶部中间弹出，必须点「×」才会关闭；重新发布即覆盖旧公告，随时可撤下。
